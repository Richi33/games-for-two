# 🎮 Ігри на двох (PWA)

Онлайн-ігри для двох гравців з різних пристроїв + колесо покарань для того, хто програє.
Це **PWA**: працює в браузері й встановлюється на телефон («Додати на головний екран») —
**без сертифікатів розробника, App Store та Google Play**.

## Ігри (19)
**Настільні:** Хрестики-нулики · Шашки · Морський бій · Крапки й квадрати · Нім

**Інтелектуальні та словесні:** Вікторина · Шибениця (3 складності, укр/рос слова) · Анаграми (укр/рос слова) · Дуель рахунку · Вгадай число · **Wordle** (укр/рос, слова 5–8 літер, 6 спроб, змагання на одному слові)

**Швидкість, пам'ять, блеф:** Дуель реакції · Пам'ять (3 складності) · Камінь-ножиці-папір · Кості-блеф

**Карткові:** Дурень переводний (колода 36 або 52 карти) · Двадцять одне

**Карткові:** Дурень (звичайний/переводний, 24/36/52) · Двадцять одне

**Для спілкування та креативу:** Що б обрав ти (20 тем) · Наскільки добре знаєш (текст, картинки, шкала) · Правда або дія · **Діксіт** для двох (84 згенеровані картки-асоціації) · **Чорні карти** (чорний гумор, режим 18+)

## Налаштування в лобі
- **Складність** (Пам'ять, Шибениця): легко / звичайно / складно.
- **Режим** (Що б обрав ти, Наскільки добре знаєш, Правда або дія, Чорні карти): звичайний або 🔞 18+ (флірт і пікантні питання без відвертого вмісту; потрібне підтвердження віку).
- **Тема** для «Що б обрав ти»: 20 звичайних і 6 тем 18+ або мікс.
- **Колода** (Дурень): 36 або 52 карти.
- **Варіант і колода** (Дурень): звичайний або переводний; 24, 36 або 52 карти.
- **Мова слів** (Шибениця, Анаграми, Wordle): українська або російська; **довжина слова** для Wordle — 5–8 літер.
- 📖 Правила вибраної гри показуються в лобі; у грі кнопка ❓ відкриває їх знову.
- У кожній грі є 🏠 (повернутись у меню вибору гри для обох) і ✕ (вийти з кімнати).
- 🔊 вимикач звуку початку гри. Після гри: «Почати заново» або «В меню».

Тексти питань і завдань лежать у `content.js` — їх легко доповнювати. Картинки в «Наскільки добре знаєш» — емодзі; щоб додати власні зображення, покладіть файли в проєкт і додайте їх у `STATIC` у `server.js`.

## Запуск
```bash
npm install
npm start          # http://localhost:3000
```
Відкрийте на двох вкладках/пристроях: один «Створити кімнату», другий вводить 4-символьний код
(або відкриває посилання з кнопки «Запросити друга»).

## Колесо покарань
У лобі увімкніть «З покаранням». Додавайте/видаляйте покарання (список спільний для обох).
Після «Почати гру» колесо крутиться **перед грою**, обоє бачать один результат.
Програвший отримує це покарання — воно показане під час гри й у фіналі. Нічия — без покарання.

## Як зробити доступним через інтернет
Для встановлення на телефон потрібен **HTTPS** (його дає хостинг, свій сертифікат не потрібен):
- **Render.com / Railway / Fly.io** — підключіть репозиторій, команда запуску `npm start`
  (підтримують WebSocket, порт береться зі змінної `PORT`).
- **Швидкий тест з телефона:** `npx cloudflared tunnel --url http://localhost:3000`
  (або ngrok) — отримаєте https-адресу.

## Встановлення на телефон
- Android (Chrome): меню ⋮ → «Установити застосунок».
- iPhone (Safari): «Поділитися» → «На початковий екран».

## Додати нову гру
У `games3.js` (або `games2.js` / `games.js`) додайте об'єкт `{ init, move, view }` (+ необов'язковий `start`), експортуйте його;
у `extra2.js` додайте запис у `GAMES` і функцію відображення `R.<id>`, а короткі правила — у `rules.js`.
Уся логіка на сервері, тому шахрувати з клієнта неможливо.

## Словники Wordle
Слова лежать у `dict/` (gzip, завантажуються сервером при першій грі): допустимих слів довжиною 5–8 літер —
**~464 тис. українських і ~265 тис. російських** (разом понад 700 тис.), а загадуються лише поширені слова в початковій формі
(~5 тис. укр. / ~7 тис. рос.). Скрипт збірки — `tools/build_dict.py`.
Джерела: Hunspell-словники LibreOffice (укр. — проєкт [dict_uk](https://github.com/brown-uk/dict_uk), ліцензія MPL 1.1; рос. — А. І. Лебедєв, BSD-подібна ліцензія)
та частотні списки [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC-BY-SA 4.0). У російській «ё» = «е».
